# Kad Kahwin Digital: Harith & Aisyah (Walimatulurus)

Laman web kad jemputan perkahwinan digital interaktif dengan **Swiper Parallax Slider Transitions** berinspirasikan reka bentuk editorial mewah [#28 Slider Transitions (Mirko Zorić)](https://prismic.io/blog/css-scroll-effects#28-slider-transitions).

---

## 🌸 Ciri-Ciri Utama (Key Features)

1. **Pengalaman Gelangsar Parallax Penuh (Full-Screen Swiper Engine)**:
   - Dikuasakan oleh `swiper` dengan modul `Parallax`, `Mousewheel`, `Pagination`, `Navigation`, dan `Keyboard`.
   - Mengisi keseluruhan skrin (`100vw`, `100vh`) dengan navigasi leretan sesentuh (*touch swipe* pada telefon) dan putaran tetikus (*mousewheel scroll* pada desktop).

2. **Penapis Warna CSS Dinamik (Dynamic CSS Filters)**:
   - Efek peralihan warna sinematik antara slaid tidak aktif (`brightness`, `contrast`, `saturate`) kepada ton berseri keemasan (*warm bloom*) apabila slaid menjadi aktif.

3. **6 Babak Lengkap Perkahwinan (Slide Chapters)**:
   - **01. Pintu Gerbang**: Sambutan Walimatulurus & nama mempelai Harith & Aisyah.
   - **02. Kalam Suci**: Surah Ar-Rum: 21 berserta terjemahan dan suar cahaya mentari keemasan.
   - **03. Kira Detik & Lokasi**: Jam kira detik masa nyata (*Live Countdown*), lokasi The Glasshouse Seputeh, serta pautan Google Maps & Waze.
   - **04. Raja Sehari & Atur Cara**: Profil pasangan, maklumat ibu bapa kedua-dua pihak, dan jadual majlis.
   - **05. Sahkan RSVP**: Borang RSVP interaktif penuh (pilihan Hadir/Tidak, bilangan pax, no telefon, ucapan, dan animasi *confetti*).
   - **06. Buku Ucapan & Hadiah**: Dinding ucapan langsung, maklumat Salam Kaut DuitNow Maybank, dan pautan WhatsApp keluarga.

4. **Sistem Pengurusan RSVP (Admin Dashboard)**:
   - Butang mod admin untuk melihat senarai kehadiran tetamu, jumlah *headcount*, dan eksport data ke fail CSV.

5. **Pemain Muzik Latar Terapung (Ambient Music Player)**:
   - Memainkan alunan muzik romantik dengan butang kawalan *Play/Pause* dan *Mute*.

---

## 🚀 Panduan Pemasangan & Menjalankan Projek

```bash
# 1. Pasang kebergantungan (dependencies)
npm install

# 2. Jalankan mod pembangunan (development)
npm run dev

# 3. Bina untuk produksi (production build)
npm run build
npm run start
```

Layari `http://localhost:3000` di pelayar web anda.
